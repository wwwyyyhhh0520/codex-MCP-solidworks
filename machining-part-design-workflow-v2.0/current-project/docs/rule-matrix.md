# 人工出图规则到程序规则映射

| 规则域 | 输入事实 | 程序规则 | 输出/风险 |
|---|---|---|---|
| 零件分类 | 实体数、包围盒、回转面、主要平面 | 单实体且回转特征占优 -> 轴类；大平面占优 -> 板类；否则铣削块候选 | 低置信度需确认 |
| 主视图 | 面/边投影、关键 Feature | 最大化关键结构可见、最小化隐藏线，并考虑加工姿态与基准 | 候选方向+理由 |
| 投影视图 | 各方向新增可见特征 | 新增信息不足则拒绝视图 | 视图计划 |
| 剖视 | 内部特征、隐藏线密度 | 内部结构不可清晰定义或隐藏线过多 -> 剖视候选 | 需核验剖切路径 |
| 尺寸 | 几何测量、草图/PMI | 先功能和定位，再定形、总体；重复项转参考或报错 | 尺寸来源可追溯 |
| 孔/螺纹 | Hole Wizard、Thread、圆柱面 | 结构化参数优先；无参数不推断规格 | 不确定项 |
| 基准 | PMI、属性、平面/轴线 | 明确标记优先，否则只生成候选 | 不得伪造 A/B/C |
| 公差/GD&T | PMI、DimXpert、规则配置 | 仅复制有来源的要求 | 缺失不补齐 |
| 排版 | 视图/标注包围盒 | 避免重叠、越界、穿线；必要时升级图幅 | Reviewer 检查 |
