# machining-part-design-workflow

## Trigger Conditions
Use when the task involves:
- machining part design
- CAD analysis
- CAD modification
- drawing generation
- engineering validation

## Agent Responsibilities
The Agent:
- understands user objectives
- selects workflow phases
- requests missing inputs
- invokes tools

## Workflow
Requirement Analysis
-> CAD Analysis
-> Semantic Extraction
-> Design Execution
-> Drawing Generation
-> Validation
-> Delivery

## Stop Conditions
Stop and request human review when:
- requirements are incomplete
- design intent is unclear
- critical dimensions conflict
- validation fails

## Human Confirmation
Required for:
- design intent
- critical dimensions
- datum strategy
- final release
